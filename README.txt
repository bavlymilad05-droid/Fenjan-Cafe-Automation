Fenjan Café Live Portfolio

Files included:
- index.html
- styles.css
- script.js
- assets/fenjan-logo.svg
- workflows/*.json

What it does:
- Café-themed landing page
- Arabic / English toggle
- Dark mode toggle
- Interactive menu + order builder
- Delivery / pickup selection
- Order summary generator
- Copy order text button
- Open Instagram / Messenger chat buttons
- Workflow showcase with downloadable n8n JSON files

Before publishing:
1) If you want to change chat links, open script.js and edit:
   - config.instagramUrl
   - config.instagramFallback
   - config.messengerUrl
2) Upload the whole folder to GitHub Pages or any static hosting.
3) If you want the order to submit directly to a backend later, the order builder can be connected to an n8n webhook.
